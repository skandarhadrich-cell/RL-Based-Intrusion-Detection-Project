# Mask-free PER - training report

`data/processed/maskfree_per_report.md` - generated by `PYTHONPATH=src python -m rl_ids.train_maskfree`

## 1. Setup

- Environment: `IDSEnv2018(split="train", mask_actions=False)`, 17-feature **real-flow** observations with Gaussian noise and telemetry masking (partial observability).
- **No action mask.** Every one of the 6 actions is offered in every state; the agent gets no hint of which actions are playbook-legal. It must infer the hidden severity bucket from the 17 features alone.
- The MDP is otherwise unchanged: the mask-free exact Bellman solution has the *same* optimal policy and value as the masked one (Normal 8.721, Suspicious 23.163, Compromised 14.508).
- Algorithm: **Double DQN + PER** - priority sampling with importance-sampling correction.
- Network: MLP [128, 128] (ReLU), Adam lr=0.001, Huber loss, grad-clip=10.0.
- Episodes = 5,000 (exploring starts), steps = 23,433, updates = 21,434; obs pool ≤ 200,000 rows/state; γ = 0.9; seed = 7.
