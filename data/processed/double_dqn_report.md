# Double DQN - training report

`data/processed/double_dqn_report.md` - generated by `PYTHONPATH=src python -m rl_ids.train_dqn`

## 1. Setup

- Environment: `IDSEnv2018(split="train")`, 17-feature **real-flow** observations with Gaussian noise and telemetry masking (partial observability). The hidden severity bucket drives transitions/rewards and is never an observation.
- Action mask: the playbook mask (`info["action_mask"]`) is applied at every argmax (acting and bootstrapping); the Q-network sees only the 17 features.
- Algorithm: **Double DQN** - online net selects `a* = argmax_a Q_online(s',a)`, target net evaluates `y = r + γ·Q_target(s',a*)`.
- Network: MLP [128, 128] (ReLU), Adam lr=0.001, Huber loss, grad-clip=10.0.
- Replay: uniform, capacity 200,000, batch 64, warm-up 2,000 transitions, target sync every 1,000 updates.
- Exploration: ε 1 → floor 0.05, ×0.995 per episode (final ε = 0.0500).
- Episodes = 5,000 (exploring starts, uniform over {Normal, Suspicious, Compromised}), steps = 21,600, updates = 19,601.
- Obs pool ≤ 200,000 rows/state; γ = 0.9; seed = 7.
