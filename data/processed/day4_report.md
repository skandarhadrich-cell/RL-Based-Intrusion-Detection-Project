# Day 4 Report - Tabular sanity check (first-visit MC control)

`data/processed/day4_report.md` - generated by `PYTHONPATH=src python -m rl_ids.train_day4`

## 1. Setup

- World: 3-state tabular bucketing of `IDSEnv2018` (agent uses `info["mdp_state"]` - perfect state perception).
- Algorithm: **First-Visit Constant-α GLIE Monte Carlo control**.
- γ = 0.9, α = 0.05, ε_t = 1/(1 + t/1000) (ends at ε = 0.0244).
- Explore-starts: each episode begins uniformly over {Normal, Suspicious, Compromised} (an eps-greedy run starting only at Normal would reach Suspicious ~3% of episodes and starve it).
- Episodes = 40000, obs pool capped at 3k rows/state (transitions/rewards are RNG-only; pool size does not bias them).
- seed = 11

## 4. Gap vs the Day-4 slide targets

Slide targets `N→Monitor 18.29 / S→Honeypot 28.61 / C→Block 31.06` assume a *different* reward convention than the Day-3 checkpoint we locked in. In our model a stationary Compromised flow capped by Block-persist ** −2 ** per step satisfies `q(C,Block) = 0.503·(−2+0.9·q) + 0.497·18 ⇒ q ≤ 18`. The exact q* here is therefore:

The **optimal policy is identical**; only the scale of the stationary q-values differs (documented decision in `docs/day3.md`). `q(N,Monitor)` inherits the cap through the N→C branch.
